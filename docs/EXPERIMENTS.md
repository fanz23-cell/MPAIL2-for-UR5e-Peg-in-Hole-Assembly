# 实验记录与指标口径

本页把仓库中的主要实验线索整理成可核查的阶段和结果。原始 logs、W&B 下载目录、模型权重和专家数据未全部提交；精简数值表在 results/selected_runs.csv，证据路径保留原实验目录名，便于在原实验盘或 W&B 记录中查找。

## 实验流程

1. **先接通任务。**在 Isaac Sim / Isaac Lab 中适配 UR5e 与 Robotiq 2F-85 插孔任务，检查 reset、终止信号、动作尺度和夹爪开合方向。早期先用已抓取插入的 Route A 隔离接触和对准问题，再尝试完整的接近、抓取、插入任务。
2. **调整观测和基础策略。**对比 13、19、22 维紧凑状态，检查策略输入是否包含完成插入所需的相对几何信息。随后比较纯策略与 MPPI 规划，调试规划动作对基础策略的实际影响。
3. **整理示范与预训练。**使用 OmniReset teacher 导出的示范，转成状态、动作和后继状态样本。后期完整任务路线使用 215 维观测，在 S189b / S190 训练中记录了 8177 条专家转移；配置加入 IQ-Learn 预训练、BC 动作监督和受保护的示范回放。示范 teacher 来自任务提供方，本项目没有训练一个新的 expert。
4. **扩展到完整任务并做消融。**S192 / S193 在 32 个并行环境中沿用完整任务设置，尝试固定规划温度、无 ensemble 和无 weight normalization 等配置。S192c 的配置上限是 500 次迭代，但已保存日志到迭代 208；不能把计划次数当成完成次数。

这条迭代路径体现的是把算法和任务接起来、检查监督信号、规划动作和训练指标是否吻合。它没有收敛到一个已验证的完整任务成功方案。

## 结果

### Route A 的短控制对照

S163 / S164 使用 32 个并行环境、每次 20 个评估迭代。CSV 中的 success_mean 是评估期间环境处于 success 状态的占比均值：

| 实验 | 控制方式 | 平均成功状态占比 | 迭代间标准差 |
|---|---|---:|---:|
| S164 | 纯基础策略 | 52.26% | 6.64 个百分点 |
| S163 第一次 | 基础策略 + MPPI，blend=0.05 | 52.09% | 5.36 个百分点 |
| S163 第二次 | 基础策略 + MPPI，blend=0.05 | 53.07% | 5.19 个百分点 |

这里的标准差是 20 个迭代值之间的波动，不是多个随机种子之间的差异。统计单位是并行环境和控制步上的成功状态，不是独立回合的成功率。两次 MPPI 混合结果与纯基础策略相近，不支持稳定提升的结论；记录中的平均实际动作修正也只有约 0.0015。

### 后期完整任务训练记录

S189b、S190、S192b、S192c、S193a 和 S193b 的已保存训练日志中，Env/success_rate 与 task_command/end_of_episode_success_rate 两个字段的最大值均为 0。各次运行实际保存行数与迭代计划如下：

| 实验 | 已保存迭代 / 计划迭代 | 训练日志中的两个 success 字段 |
|---|---:|---:|
| S189b | 100 / 100 | 最大值均为 0 |
| S190 | 300 / 300 | 最大值均为 0 |
| S192b | 100 / 100 | 最大值均为 0 |
| S192c | 209 / 500 | 最大值均为 0 |
| S193a | 30 / 30 | 最大值均为 0 |
| S193b | 27 / 30 | 最大值均为 0 |

这表示在这些保存的训练记录里没有观察到成功信号；不能把它解释成独立测试集上经过统计的 0% 回合成功率。S192c 在训练保存日志中只到 it=208，500 是配置的计划上限。

## 指标说明

- S163 / S164 的 success_mean 汇总并行环境中各控制步的 success 状态。约 52% 表示评估采样期间有约 52% 的环境步处于 success 状态；它不等同于回合成功比例。
- 训练日志中的 Env/success_rate 是 runner 对环境 success 状态的记录，同样不能直接按回合成功率解读。
- Metrics/task_command/end_of_episode_success_rate 是单独记录的任务回合结束指标。后期完整任务日志中，该字段和 Env/success_rate 都没有非零值。
- 目前这些对照没有多随机种子置信区间，也没有统一的独立 held-out 测试集。把迭代间波动称为统计显著性是不成立的。

## 未纳入主结果的诊断记录

曾有一个旧版 S170 weak-base 混合控制脚本记录 10 回合中 4 回合触发 success；它使用 60 维 legacy planner、S55 base policy，并按参数名称和形状加载兼容 checkpoint 权重，不等于原生 215 维 S192c 完整模型评估。标为 S192c positive-control 的另一个 JSON 与该记录的前 4 回合字段完全相同，因此不作为独立复现实验或增益证据。README 不把这个 4/10 数字与后期完整任务结果混写。

## 数据和复现边界

专家数据来自 OmniReset 导出的 teacher 示范。本仓库提供数据读取和转换入口，但没有因为体积、checkpoint 依赖和数据来源问题而把全部原始轨迹、模型权重与训练日志打包进 Git。具体源代码版本及两个环境补丁见 docs/SOURCE_VERSIONS.md 与 patches/README.md。

复现这些运行需要准备对应的 Isaac Sim / Isaac Lab / UWLab 版本、已转换的专家数据和 teacher policy，并匹配脚本指向的源码树。当前仓库没有经过干净机器上的端到端复现验证。表格用于准确交代已有记录，不替代完整的原始训练归档。
